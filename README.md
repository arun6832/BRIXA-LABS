# BRIXA LABS

A responsive, single-page landing site for a premium digital invitation studio. Built with semantic HTML, CSS and vanilla JavaScript; no build step or framework is required.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Studio configuration

Before launch, update the clearly marked contact placeholders in `index.html`:

- Replace `hello@example.com` in the email links with the studio inbox.
- Replace `YOUR_NUMBER` in the WhatsApp URL with the international phone number, digits only.
- Replace `yourstudio` in the Instagram URL with the studio account.
- Update the invitation concepts and copy to match the studio's real work and offer.

The six projects shown are illustrative design concepts, not commissioned client projects. The copyright year is set by `js/script.js`.

## Design notes

The invitation artwork is composed from CSS and typography, so the page does not depend on external stock image URLs. The visual system uses muted sage grey (`#a5a79b`), warm cream beige (`#e8d2b5`) and deep burgundy (`#590907`). Cultural references are presented as directions to tailor to each customer's own traditions, not as a default aesthetic. The signature experiences section describes optional features rather than a fixed package. Google Fonts are progressively enhanced; system fallbacks are included. The mobile navigation is keyboard operable, the page has a skip link and visible focus behavior from browser defaults, and motion is disabled for users who request reduced motion.
